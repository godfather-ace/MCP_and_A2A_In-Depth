# Stock Price MCP Server on Databricks

A step-by-step guide to deploying the **Stock Price MCP Server** — a custom Model Context Protocol (MCP) server that exposes real-time and historical stock data via `yfinance` — on Databricks Apps.

---

## What This Server Does

The server exposes **3 tools** and **1 resource** to any MCP-compatible AI agent:

| Name | Type | Description |
|------|------|-------------|
| `get_stock_price` | Tool | Returns the latest closing price for a ticker symbol |
| `get_stock_history` | Tool | Returns historical OHLCV data as a CSV string |
| `compare_stocks` | Tool | Compares current prices of two ticker symbols |
| `stock://{symbol}` | Resource | Returns a human-readable price string for a symbol |

---

## Prerequisites

- Databricks workspace with **Managed MCP Servers preview** enabled
- Databricks CLI installed locally
- Python 3.13+
- `uv` installed (`pip install uv`)
- `databricks-sdk` and `databricks-mcp` installed locally for running the client

---

## Project Structure

All files live flat in the project root — no `server/` subdirectory:

```
mcp-server-dbrss/
├── main.py           # MCP server (tools + resources)
├── run.py            # Local test client
├── app.yaml          # Databricks Apps startup config
├── pyproject.toml    # Dependencies + script entry point
├── requirements.txt  # Tells Databricks to use uv
├── __init__.py       # Empty, marks root as a package
└── uv.lock           # Auto-generated by uv
```

## Step 2 — Create the Files

### `main.py`

The MCP server. All tools are defined here with `@mcp.tool()` and the resource with `@mcp.resource()`.

```python
from mcp.server.fastmcp import FastMCP
import yfinance as yf
import os

# Create an MCP server with a custom name
mcp = FastMCP("Stock Price Server")

@mcp.tool()
def get_stock_price(symbol: str) -> float:
    """
    Retrieve the current stock price for the given ticker symbol.
    Returns the latest closing price as a float.
    """
    try:
        ticker = yf.Ticker(symbol)
        data = ticker.history(period="1d")
        if not data.empty:
            price = data['Close'].iloc[-1]
            return float(price)
        else:
            info = ticker.info
            price = info.get("regularMarketPrice", None)
            if price is not None:
                return float(price)
            else:
                return -1.0  # Indicate failure
    except Exception:
        return -1.0  # Return -1.0 to indicate an error

@mcp.resource("stock://{symbol}")
def stock_resource(symbol: str) -> str:
    """
    Expose stock price data as a resource.
    Returns a formatted string with the current stock price for the given symbol.
    """
    price = get_stock_price(symbol)
    if price < 0:
        return f"Error: Could not retrieve price for symbol '{symbol}'."
    return f"The current price of '{symbol}' is ${price:.2f}."

@mcp.tool()
def get_stock_history(symbol: str, period: str = "1mo") -> str:
    """
    Retrieve historical data for a stock given a ticker symbol and a period.
    Returns the historical data as a CSV formatted string.

    Parameters:
        symbol: The stock ticker symbol.
        period: The period over which to retrieve historical data (e.g., '1mo', '3mo', '1y').
    """
    try:
        ticker = yf.Ticker(symbol)
        data = ticker.history(period=period)
        if data.empty:
            return f"No historical data found for symbol '{symbol}' with period '{period}'."
        csv_data = data.to_csv()
        return csv_data
    except Exception as e:
        return f"Error fetching historical data: {str(e)}"

@mcp.tool()
def compare_stocks(symbol1: str, symbol2: str) -> str:
    """
    Compare the current stock prices of two ticker symbols.
    Returns a formatted message comparing the two stock prices.

    Parameters:
        symbol1: The first stock ticker symbol.
        symbol2: The second stock ticker symbol.
    """
    price1 = get_stock_price(symbol1)
    price2 = get_stock_price(symbol2)
    if price1 < 0 or price2 < 0:
        return f"Error: Could not retrieve data for comparison of '{symbol1}' and '{symbol2}'."
    if price1 > price2:
        result = f"{symbol1} (${price1:.2f}) is higher than {symbol2} (${price2:.2f})."
    elif price1 < price2:
        result = f"{symbol1} (${price1:.2f}) is lower than {symbol2} (${price2:.2f})."
    else:
        result = f"Both {symbol1} and {symbol2} have the same price (${price1:.2f})."
    return result

def main():
    port = int(os.environ.get("PORT", 8000))
    mcp.run(transport="streamable-http", host="0.0.0.0", port=port)

if __name__ == "__main__":
    main()
```

> **Key rule:** Always use `transport="streamable-http"` with `host="0.0.0.0"` — the default stdio transport does **not** work on Databricks Apps.

### `pyproject.toml`

Declares dependencies and registers `mcp-server-dbrss` as the script entry point pointing to `main:main` (root-level `main.py`, `main()` function).

```toml
[project]
name = "mcp-server-dbrss"
version = "0.1.0"
description = "Stock Price MCP Server"
readme = "README.md"
requires-python = ">=3.13"
dependencies = [
    "httpx>=0.28.1",
    "mcp[cli]>=1.8.0",
    "yfinance>=0.2.59",
]

[project.scripts]
mcp-server-dbrss = "main:main"
```

> **Important:** The script name `mcp-server-dbrss` must exactly match the command in `app.yaml`.

---

### `app.yaml`

Tells Databricks Apps how to start the server. The command matches the `[project.scripts]` key in `pyproject.toml`.

```yaml
command: [
  'uv',
  'run',
  'mcp-server-dbrss',
]
env:
  - name: PORT
    value: "8000"
```

> **Note:** The Databricks app name must start with `mcp-` to be recognized as an MCP server in the AI Playground.

---

### `requirements.txt`

Tells the Databricks build system to use `uv` for dependency management. Must also include `-e .` to install the local project and register the `mcp-server-dbrss` script — without this, `uv run mcp-server-dbrss` fails with `No such file or directory`.

```
uv
-e .
```

Empty file — marks the root directory as a Python package so `main:main` resolves correctly.

### `run.py`

Local test client. Run this after a successful deployment to verify tools are reachable.

```python
from databricks_mcp import DatabricksMCPClient
from databricks.sdk import WorkspaceClient

mcp_server_url = "https://<your-app-url>.aws.databricksapps.com/mcp"
workspace_client = WorkspaceClient(profile="DEFAULT")

mcp_client = DatabricksMCPClient(
    server_url=mcp_server_url,
    workspace_client=workspace_client
)

# List available tools
tools = mcp_client.list_tools()
print(f"Available tools: {tools}")

# Get current price for Apple
price = mcp_client.call_tool("get_stock_price", {"symbol": "AAPL"})
print(price)

# Get 3 months of history for Tesla
history = mcp_client.call_tool("get_stock_history", {"symbol": "TSLA", "period": "3mo"})
print(history)

# Compare Microsoft vs Google
comparison = mcp_client.call_tool("compare_stocks", {"symbol1": "MSFT", "symbol2": "GOOGL"})
print(comparison)
```

## Step 3 — Generate the Lock File

Before deploying, regenerate `uv.lock` to reflect the current `pyproject.toml`:

```bash
rm uv.lock          # delete stale lock file
uv lock             # regenerate
uv sync             # install locally and register the script
```

Verify the script is registered and works locally before deploying:

```bash
uv run mcp-server-dbrss
# Expected: Uvicorn running on http://0.0.0.0:8000
```

---

## Step 4 — Deploy to Databricks

From inside your `mcp-server-dbrss/` directory:

```bash
# Create the app (only needed once)
databricks apps create mcp-server-dbrss

# Get your Databricks username
DATABRICKS_USERNAME=$(databricks current-user me | jq -r .userName)

# Sync source code to workspace
databricks sync . "/Users/$DATABRICKS_USERNAME/mcp-server-dbrss"

# Deploy
databricks apps deploy mcp-server-dbrss \
  --source-code-path "/Workspace/Users/$DATABRICKS_USERNAME/mcp-server-dbrss"
```

---

## Step 5 — Verify Deployment

Check the logs to confirm the server started successfully:

```bash
databricks apps logs mcp-server-dbrss --tail-lines 50
```

Look for this line — it confirms the server is up:
```
Uvicorn running on http://0.0.0.0:8000
```

Your MCP endpoint is then live at:
```
https://<app-url>.aws.databricksapps.com/mcp
```

## Troubleshooting

| Error | Cause | Fix |
|-------|-------|-----|
| `Failed to spawn: mcp-server-dbrss` | Script not installed | Add `-e .` to `requirements.txt` and delete + regenerate `uv.lock` |
| `Requirements have not changed. Skipping installation` | Stale `uv.lock` | Run `rm uv.lock && uv lock` then redeploy |
| `502 Bad Gateway` | App not running or URL wrong | Check logs for `Uvicorn running`; confirm URL ends in `/mcp` |
| `app exited unexpectedly` | Wrong transport | Ensure `mcp.run(transport="streamable-http", host="0.0.0.0")` |
| Price returns `-1.0` | Bad symbol or market closed | Verify ticker; retry when market is open |

```bash
# Always check logs first
databricks apps logs mcp-server-dbrss --tail-lines 50
```
